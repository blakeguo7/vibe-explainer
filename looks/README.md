# 外观卡样例

这里是三张按 `references/look.md` 推好的外观卡，每张都实际渲染过。它们不是可选的模板：
新片的外观照样要从自己的内容推出来，这里只是拿来对照"推完以后大概是什么样"。

| 卡 | 适合 | 一句话 |
|---|---|---|
| `dark-instrument.md` 暗场仪器 | 算法、数学、信息这类抽象概念 | 深色星点底，宋体大字，冷蓝和金 |
| `blueprint.md` 蓝图 | 数据库、网络、操作系统这类技术系统 | 深蓝网格底，黑体字幕逐字亮起，琥珀色的数据在走 |
| `paper.md` 纸面 | 生活、心理、行为，或者历史 | 米色纸面，深棕宋体字，不发光 |

每张卡最后都附了对应的 `LOOK` 代码，可以对照着看外观卡的每一项怎么变成代码。
