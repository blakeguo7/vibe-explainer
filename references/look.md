# 外观：按内容推出来

这里没有可选的模板。每条片的外观，是从它的内容推出来的：先守住第一节的底线，再回答第二节的四个问题，最后写成第三节的外观卡。
`looks/` 里有三张推好的外观卡，可以看它们怎么从题材落到颜色和画法，但不要整套照搬。

## 一、画面底线（任何外观都守）

- **画布和安全区。** 横屏 1920×1080，竖屏 1080×1920，都是每秒 30 帧。左右各留 5%。
- **三个区不串位。** 主体区在上面；字幕区横屏是纵向 80%–95%，竖屏是 70%–82%（竖屏往上提，避开平台的按钮和文案），只放字幕；四角放常驻元素。
- **一个主体，三成留黑。** 每一刻只有一样东西是亮的、在动的；别的退到三成以下的亮度。画面三成以上是空的，别用装饰填空。
- **颜色是词汇。** 每种颜色全片只有一个意思；除了主体字和标注，强调色不超过三种。字幕里一句最多染一处颜色，三句里至少两句不染。
- **看得清。** 字幕和底的亮度要拉开；压在亮底上的字加投影、加底板，或者把底压暗。缩到手机大小，字幕和标注都读得出来（字幕 40 像素以上，标注 20 像素以上）。
- **实心的东西不发光。** 辉光会把大块实心颜色冲成一团白：有体积的东西画在底层（`f.under()`），发光的线和字画在上层。
- **动效的手感。** 字是显影出来的，不是飞进来的；线是画出来的；数是数上去的；只有真的东西落地才弹；镜头之间不硬切。

## 二、四个问题

按顺序回答。每个问题的答案，决定外观卡里的几项。一条片可以落在两行之间，那就混着用，但要说得出为什么。

### 1. 题材是什么性质？决定底和画法

| 题材 | 底 | 画法 | 样例 |
|---|---|---|---|
| 抽象概念（算法、数学、信息） | 深色暗场，一点点星点 | 大字、细线、带刻度的仪器，题材本身就是字和数 | `looks/dark-instrument.md` |
| 技术系统（数据库、网络、操作系统） | 深色网格，像图纸 | 把部件画成认得出的东西：机器、柜子、信封、管道，再贴小字 | `looks/blueprint.md` |
| 生活、心理、行为 | 浅色纸面，或者每场一幅插画 | 扁平色块、角色、远中近三层 | `looks/paper.md` |
| 历史、一样东西的演变 | 暖色暗场或旧纸 | 实物感的小道具、年份、文献 | 从 `paper.md` 改暖、改旧 |
| 自然、生物、身体 | 深色 | 有体积和材质的实物，从认得的画面推进去 | 从 `dark-instrument.md` 改，实物画在底层 |

### 2. 语气是什么？决定颜色的温度、节奏和音色

| 语气 | 颜色 | 节奏 | 音色 |
|---|---|---|---|
| 冷静 | 冷色、低饱和 | 字幕停留长，镜头慢 | 轻、短，重音少 |
| 好奇 | 冷底配一个暖色的强调色 | 常用"先藏后揭" | 揭晓那一下亮一点 |
| 温暖 | 暖色、纸张感 | 中速 | 柔和 |
| 紧张 | 高对比，警示色用得多一点 | 句子短、换得快 | 低沉、有冲击 |
| 幽默 | 明亮、扁平 | 角色动作多，留"反应"的停顿 | 俏皮的短音 |

### 3. 屏上的主体主要是什么？决定字体和辉光

| 主体 | 字体 | 辉光 |
|---|---|---|
| 字和符号 | 宋体大字，字距大 | 开（约 0.8） |
| 机器、仪器和图表 | 黑体字幕、等宽小标 | 中（约 0.4） |
| 有体积的实物 | 宋体或黑体都行 | 低（约 0.3），实物画在底层 |
| 场景和角色，浅色底 | 粗一点的字幕 | 关（0） |

### 4. 观众在哪看？决定画幅、字号和字幕节奏

| 在哪看 | 画幅 | 字幕 |
|---|---|---|
| 电脑、横屏的手机 | 16:9 | 一行，中文一般不超过 22 个字；要英文行时每句停留长一点 |
| 竖屏的手机 | 9:16 | 字号更大，一行不超过 16 个字；位置往上提 |

## 三、外观卡模板

推完以后写成这张卡，存成工程里的 `look.md`，放在分镜表旁边。`film.js` 里的 `LOOK` 全部照它填（字段对应见 `engine.md` 第三节）。改外观先改卡。

```
# 外观卡：《片名》

为什么这样选：题材是……；语气是……；主体主要是……；观众在……看。

画幅：16:9 / 9:16
底：（纯色 / 星点 / 网格 / 纸面；底色、中间那团光）
颜色：（每种一个意思，全片不破例）
  ink      #……  主体字
  dim      #……  标注
  accent   #……  = ……（字幕里 {词} 用它）
  warn     #……  = ……（字幕里 {!词} 用它）
  （还需要的颜色，写名字和意思）
字体：字幕 …… / 大字 …… / 小标 ……
画法：（线描 / 扁平插画 / 有体积的实物 / 以字为主）
辉光、颗粒、暗角：
字幕：字号 ……，出现方式（整行淡入 / 逐字亮起 / 逐字由虚变实），每句停留约 …… 秒，要不要英文行，要不要底板
常驻元素：（最多两三样，每样都报一个数据，比如角上的计数）
转场：（从溶解、推近、翻过去、留一个点、闪、暗一下里挑 2–4 种）
片名卡：
音色：（重音：片名、落地、揭晓各用哪个；轻音：卡片落位、一步步往下、东西滑进来各用哪个）
```

## 四、怎么验证

外观卡写完，先做一张样帧（钩子里最典型的一镜），再做这几件事：

- 遮住字幕和小字，过三问：这是什么、它在干什么、我明白了什么。
- 缩到手机大小看一遍，字读得清吗？
- 对一遍颜色：屏上每种颜色都在卡里，意思没有用岔。
- 和 `looks/` 里最接近的那张并排放：主体有那么大、那么干净吗？

过不了就改卡，再重做样帧。

## 五、我们常做的题材

我们的片子大多讲计算机：数据库、计算机网络、数据结构和算法、操作系统。这几类的起点：

- **数据库**（索引、事务、锁、缓存）：技术系统，冷静里带一点好奇。从 `blueprint.md` 起步；书、柜子、锁这些比喻物画成有体积的实物。
- **计算机网络**（分层、握手、路由、拥塞）：技术系统。从 `blueprint.md` 起步；数据包画成小信封，路由器、网线画成认得出的设备。
- **数据结构和算法**（排序、树、哈希、查找）：抽象概念。从 `dark-instrument.md` 起步；主体是数字、格子和计数。
- **操作系统**（进程、内存、调度）：技术系统和抽象概念之间。看主体是"机器"还是"格子和数字"来选。

用户对某一条有自己的想法时，以用户的为准，再按第二节的四个问题调整。
