# 外观卡：蓝图

为什么这样选：题材是技术系统（网络、数据库、操作系统），屏上的主体是机器和线路；语气冷静、清楚；观众在横屏上看。
所以底像一张深蓝色的图纸，设备画成有体积的实物；正在走的数据用一个醒目的暖色，故障用红色，其余都是冷色。

画幅：16:9
底：网格。底色 #0B1826，中间一团深蓝光（#163650），网格线 #4C7FA8，间距 48 像素，每 5 格一条粗线
颜色：
  ink      #E6EEF5  主体字
  dim      #8AA3B8  标注
  accent   #FFB547  数据、正在走的东西、关键的那条路（字幕里 {词} 用它）
  cool     #5CC8FF  设备和线路的平常状态
  warn     #FF6B6B  故障、断开、阻塞（字幕里 {!词} 用它）
字体：字幕 黑体 500 / 大字 黑体 800 / 小标和计数 等宽
画法：设备画成有体积的实物（渐变、圆角、网口、天线），画在底层；连线也画在底层，被设备盖住线头；数据包是一个会发光的小信封
辉光、颗粒、暗角：0.45 / 0.035 / 0.5
字幕：44 像素，逐字亮起，每句停留约 3.5 秒，不要英文行，投影浓一点（0.7）
常驻元素：右上角一个计数（比如"经过路由器 3"）
转场：溶解、跟着数据包推近、断开时一下红光
片名卡：黑体 800 大字逐字显影，琥珀色细线展开，副题琥珀色
音色：数据出发 pop；故障 thud；到达 tick；片名 chime

```js
const LOOK = {
  canvas: '16:9',
  bg: { type: 'grid', color: '#0B1826', glow: '#163650', glowA: .5, line: '#4C7FA8', step: 48 },
  colors: { ink: '#E6EEF5', dim: '#8AA3B8', accent: '#FFB547', cool: '#5CC8FF', warn: '#FF6B6B' },
  bloom: .45, grain: .035, vignette: .5,
  subs: { font: 'sans', weight: 500, mode: 'type', shadow: .7 },
};
// 片名卡：f.titleCard(lt, { zh, sub, en, font: 'sans', weight: 800 })
```
